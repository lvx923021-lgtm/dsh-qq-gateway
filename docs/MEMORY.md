# 记忆系统

## 为什么不能只有「一个记忆文件」

最常见的做法是写一个 `MEMORY.md`：模型觉得重要就往上写。它有三个死结：

1. **靠自觉**——忙起来就不记；
2. **摘要吃证据**——写下来的是结论，事后答不出「他当时到底怎么说的」；
3. **压缩之后不自知**——上下文被压掉一段，模型不知道自己缺了一块，开始拿「像的东西」凑。

这套的做法反过来：**原话全部落盘、只追加；按线索现算检索；要细节就给原话。**

## 五层

| 层 | 文件 | 谁写 | 生命周期 |
| --- | --- | --- | --- |
| 原话 | `raw/YYYY-MM-DD.jsonl` | 网关每轮写 | 只追加；180 天后可清 |
| 分段索引 | 内存里现算 | `memory_segments.py` | 按 20 分钟间隔 / 12 轮切段 |
| 可更正记录 | `records.jsonl` | `heart_record` 工具 | 一天最多 8 条；同一 factKey 顶掉旧的 |
| 摘要 | 插件 `summaries.jsonl` + `heart_summarize.py` | 03:50 | 14 天以上的细节收成一句 |
| 情绪回忆 | 现算 | `memory_emotion.py` | 不落盘，只算权重 |

## 检索：BM25 + 时间衰减 + 用进废退

```
得分 = BM25(中文二元组) × 时间衰减 × (1 + 0.35·log(1+被想起次数))
```

- **BM25**：词越稀有越值钱。「宝宝」「今天」这种天天出现的词几乎不加分。
- **时间衰减**：越近越容易想起。
- **用进废退**：每次被翻出来，`rehearsals.json` 记一笔，下次更容易再被想起。这就是「常被想起的事更容易想起来」。

## 可更正：factKey / superseded

```
factKey = object.aspect     例：他.睡觉时间
```

- **值永远不写进 key**。key 是「这件事是哪一类」，不是「这件事是什么」。
- 同一 factKey 再记，写新行并把旧行标 `superseded`——**旧行不删**，只是不再被读。
- 同一句话再说一遍 → 不新增，只把旧那条 `hits+1`、时间刷新（加固）。

## 遗忘：重要度半衰 + 静默归档

```python
半衰期 = 30 天 × (0.4 + 0.3 × 重要度)
重要度 1–5：有 why +1、命中约定/生病类词 +1、长期 +1、被加固过 +1、更正/承诺 +1
```

普通的 30 天淡一半，重要的事能拖到一个多月。**淡是"更难被想起来"，不是删除。**

归档规则：90 天或 300 条以外 → `notes-archive.jsonl`；带「答应/约好/第一次/生病」这类词的再老也不沉。

## 每轮注入什么、占多少

硬预算表（字，不是 token；中文约 1 字 ≈ 0.6 token）：

| 优先级 | 块 | 上限 | 来源 |
| --- | --- | --- | --- |
| 95 | 她自己定的规矩 | 按条 ≤120 | `self/rules.jsonl` |
| 90 | 约定 | 300 | `promises.jsonl` |
| 85 | 还没完的 + 这几天的 | 700 | 72h 内的笔记 + 提到「明天/还没/约好」的 |
| 80 | 上次这个时候 | 300 | 情绪回忆 |
| 75 | 她的心情 | 三行 | `mood.json`（过闸才说） |
| 70 | 记下的事 | 400 | `records.jsonl`（只给 gist + why） |
| 60 | 她给自己的小结 | 450 | 摘要 |
| 40 | 以前碰过的事 | 500 | 切段检索 |

**总计上限 3000 字。**超了按优先级**整块丢，不切句子**——宁可少一块，不留半截。

块尾永远带一句：

> （这些只是摘要和几行旧事，原话都留着；要细节我再翻。）

## 情绪回忆

他说「累」的时候，她不是问「怎么了」，而是先翻上次「累」是因为什么：

```
他：今天好累
她：上次你说累，是学生会的事堆着。这回还是那些，还是又加了新的？
```

机制：

- 情绪词表带强度（崩 3、累 2、开心 1）；
- 找同一情绪的旧记录，按「强度 × 2 + 新鲜度 × 权重」排序；
- **念头不能冒充事实**：命中的若是她自己半夜想的，前缀标「（我猜的）」；
- **12 小时内同一个情绪不重复问**（`asked.json`）——问两遍就成了审问。

## 夜里她自己想事

```
03:30  翻最近的事，挑一件没想通的，写一句念头（标「（我想的）」）
03:50  14 天以上的细节收成一句摘要
04:00  该沉的沉
```

念头也是记忆的一部分，和"他说的话"分开存。她会有猜错的时候——这是故意的，太笃定就不像人。

## 怎么手动检查

```bash
python3 memory_segments.py stats            # 切了几段、被想起过几次
python3 memory_records.py list              # 活着的记录
python3 memory_emotion.py "今天好累"        # 情绪回忆命中了什么
python3 heart_summarize.py list             # 哪些细节该收成摘要
python3 -c "import gateway; print(gateway.compose_memory('今天好累'))"   # 这一轮实际注入什么
```
