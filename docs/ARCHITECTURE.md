# 架构

## 一句话

QQ 消息进来 → 网关判断走哪条脑 → 记忆按优先级拼进去 → 回复或语音回去 → 事后记账（记忆/心情/原话）。

## 全景

```
                    ┌──────────────────────────────┐
   QQ 客户端 ──ws──▶ │ NapCat（OneBot 11，3000/3001）│
                    └──────────────┬───────────────┘
                                   │ event
                    ┌──────────────▼───────────────┐
                    │ gateway.py                    │
                    │  ① 合并连发（2s）             │
                    │  ② 原话留底（raw/日期.jsonl） │
                    │  ③ 分流：快路 / DSH / 工具    │
                    │  ④ 记忆拼装（compose_memory） │
                    │  ⑤ 发送（拆条 + 打字节奏）     │
                    │  ⑥ 事后：心情判定 / 后台补记   │
                    └───┬───────────────┬──────────┘
                        │               │
             ┌──────────▼─────┐  ┌──────▼─────────────┐
             │ 快路：直连 API │  │ DSH headless        │
             │ 2s，5 个工具   │  │ 13s，全插件+工具    │
             └────────────────┘  └──────┬─────────────┘
                                        │
                        ┌───────────────▼────────────────┐
                        │ 记忆与状态（文件系统即数据库）  │
                        │ heart/  raw/  records/ rules/  │
                        │ mood.json  self.md  ...        │
                        └────────────────────────────────┘
```

## 为什么分两条脑

| | 快路（直连 API） | 深聊（DSH headless） |
| --- | --- | --- |
| 延迟 | 约 2 秒 | 约 13 秒 |
| 上下文 | 我们自己的提示词 + 三层记忆 | 插件注入 + 工具表 + 会话历史 |
| 能用的工具 | 5 个（自己实现的） | 插件全部（B站、心事本、shell、fs…） |
| 合适什么 | 群里、寒暄、短问 | 私聊深聊、读视频、要动工具的事 |

分流规则在 `need_deep()`：超过 18 字，或命中情绪/麻烦类词，走 DSH；否则走快路。私聊默认全走 DSH（`OWNER_DSH=1`）。

## 一轮消息都发生了什么

```
收到 ──▶ 合并窗口（2 秒，连续几条并成一条）
     ──▶ 原话落盘 raw/日期.jsonl（异步，不挡）
     ──▶ 分流判定
           ├─ 快路：compose_memory() 拼记忆 → API → 草稿 → 收拾 → 成品
           └─ 深聊：call_dsh_owner() → dsh 子进程（单会话续用）
     ──▶ 发送：按自然段拆 1–3 条，条间有停顿
     ──▶ 事后（异步）：
           ├─ judge_mood()   每轮一条 JSON，更新 mood.json
           └─ remember_in_background()  值得记的写进心事本
```

## 文件即数据库

没有外部数据库，全部是本地纯文本，方便你直接打开看：

| 文件 | 内容 |
| --- | --- |
| `~/.dsh/heart/raw/YYYY-MM-DD.jsonl` | 原话，只追加 |
| `~/.dsh/heart/notes.jsonl` | 心事本（插件写） |
| `~/.dsh/heart/records.jsonl` | 可更正记录（我们写） |
| `~/.dsh/heart/self/rules.jsonl` | 她自己定的规矩 |
| `~/.dsh/heart/mood.json` | 心情状态 |
| `~/.dsh/heart/self.md` | 她自己的话 |
| `~/.dsh/heart/summaries.jsonl` | 她给自己的小结 |
| `~/.dsh/heart/promises.jsonl` | 约定 |
| `qq-session.json` | DSH 会话 id（单会话续用） |
| `history.json` | 快路对话历史 |

## 进程与守护

```
互保层 supervise.sh（20s）
 ├─ 本地 rerank（工具搜索用）
 ├─ DSH 宿主（3080，掉了就拉、地址变了发 QQ）
 └─ 看门狗 watchdog.sh（10s）
      ├─ 网关（进程 + 心跳）
      ├─ QQ（进程 或 OneBot 接口，二者取一）
      └─ DSHA App（3090 探活 → adb-shell 拉起）
```

启动顺序用 `scripts/start-stack.sh` 串行执行：互保层 → 看门狗 → 网关。

**抢锁是等待式的**（`flock -w 10` / Python 重试 20×0.5s）：抢不到不等于退出——等待期间持有锁的进程若死了，锁由内核释放，等待者接手。
